# Vansita Addanki — About page

A single static Astro page. No forms, backend, trackers or third-party requests; fonts are self-hosted in `public/fonts/`.

```sh
cd about
npm install
npm run dev       # http://127.0.0.1:4321 (localhost only)
npm run build     # static output in dist/
npm run preview   # serves dist/ at http://127.0.0.1:4321
```

Notes: Pitch Protocol and TurboML link to the portfolio (https://vansita.design/) because no precise public case-study routes were verified. No work imagery was retrieved, so type, rules and numerals carry the layout.
