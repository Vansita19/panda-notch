# Tracker Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. User approved the compact checkbox design in chat; implement within the existing Panda workspace and install the verified UI.

**Goal:** Daily habit tallies, beginning with fifteen empty Job applications slots.

**Architecture:** A bounded tracker collection and date-keyed slot masks live in the existing saved model. One focused React view renders compact rows, date navigation, an inline habit form, and recorded-day history. Existing navigation, sizing, checkbox, toast, and persistence mechanisms are reused.

**Tech Stack:** React, TypeScript, CSS, existing Radix checkbox, Node test runner. No dependencies.

**Spec:** `docs/superpowers/specs/2026-10-26-tracker-design.md`

## Global Constraints

- Tracker immediately follows To-Do.
- Exactly fifteen slots per habit per day, initially unchecked.
- Existing personal data and running sessions remain untouched by installation.
- Native Mac or Codex browser for verification; never Chrome.

## Review Focus

- Legacy saves migrate once; explicit empty lists do not repopulate.
- Checks stay attached to the intended local date through midnight, DST, and reload.
- Duplicate callbacks and malformed imports never invent or lose checked slots.
- Fifteen boxes and contextual controls fit the compact width and remain keyboard accessible.
- Multiple habits, long names, and long history scroll vertically only at the available display limit.
